终端 · 直接运行 Docker 镜像
# 匿名下载公开镜像
docker pull ghcr.io/nyakooo/oh-my-vault:latest

# 启动服务，并持久保存数据
docker run -d \
  --name personal-vault \
  --restart unless-stopped \
  -p 18741:18741 \
  -v personal-vault-data:/data \
  ghcr.io/nyakooo/oh-my-vault:latest

# 打开（服务器本机）
http://localhost:18741
数据保存在 Docker 卷personal-vault-data

自己托管，也要了解边界。

请使用 HTTPS 并保护好服务器。主密码无法找回；遗失时，只能从可用备份恢复。浏览器缓存和剪贴板清理不等于绝对安全。建议定期下载并妥善保管加密备份。
